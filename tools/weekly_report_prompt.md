# Бриф еженедельного отчёта «куда пойти одному в Москве»

Этот файл — техзадание для еженедельной задачи Клода. Правишь его — меняется
содержание отчёта; трогать саму Routine при этом не нужно.

## Кому и зачем

Фаундер AI-стартапа в Москве, ходит на события **один**. Цель — живое общение
с новыми людьми, а не пассивное сидение в зале. Отдельная задача — тренировать
«мышцу отказа»: форматы, где подойти к незнакомцу заложено в правила.

## Окно

Ближайшие 7 дней, начиная с сегодняшнего воскресенья включительно.

## Что искать

1. **Разговорные клубы и языковой обмен** — Moscow Language Exchange
   (t.me/MoscowLEM), Real Talk (t.me/RealTalk_english_speaking_club),
   English Club with Nataly (t.me/speakenglish_with_nataly). Самый надёжный
   формат на любой день недели.
2. **IT / AI / стартап-митапы и конференции** — timepad, networkly.app,
   ict2go.ru, анонсы сообществ. Приоритет темам AI-агентов, LLM, voice AI,
   dev-инструментов, DevRel-ужинам и всему, где есть фуршет-нетворкинг.
3. **Speed friending / speed dating**, в том числе IT-форматы.
4. **Мафия и настолки** — «фолбэк» на любой вечер: сборные столы, куда
   нормально прийти одному.
5. **Городские фестивали и опен-эйры** — только как дополнение, с честной
   пометкой, что знакомство там менее вероятно.

## Структура отчёта

Строго markdown, разделы в этом порядке:

- `## TL;DR` — 3 пункта: главное на сегодня, главное по будням, общий вывод.
- `## Key Findings` — что важно понимать про механику форматов этой недели.
- `## Details — план по дням` — подзаголовок на каждый день недели с датой,
  внутри пронумерованный список событий, отсортированный по пригодности для
  «прийти одному и общаться». Для каждого события: время, точный адрес и метро,
  цена, нужна ли регистрация, оценка взаимодействия, прямая ссылка.
- `## Оценка форматов по критерию «реально ли общаться с незнакомцами»` —
  градация максимум / высокий / средний / низкий.
- `## Recommendations` — что делать, плюс блок «Пороги, меняющие план».
- `## Caveats` — что перепроверить перед выходом.

## Чем искать

Основной инструмент — MCP-коннектор Bright Data: часть афиш и агрегаторов
отдаёт обычному WebFetch антибот-заглушку вместо программы, а Bright Data
пробивает и капчу, и бот-детект.

- `mcp__bd__search_engine` — поиск. Параметры: `query`, `engine`
  (`google` / `bing` / `yandex`), `geo_location: "ru"`. Прогоняй ключевые
  запросы и по Google, и по Яндексу: по русским локальным событиям выдача
  заметно разная.
- `mcp__bd__scrape_as_markdown` — вытащить одну страницу события.
- `mcp__bd__scrape_batch` — до 10 URL за раз, основной способ проверить
  пачку карточек событий разом.

Порядок работы: сначала поиск, потом обязательно `scrape` по каждой найденной
карточке на Timepad, networkly.app, ict2go.ru и KudaGo. Дату, адрес, цену и
статус регистрации бери со страницы события, а не из сниппета выдачи — в
сниппетах регулярно висят прошлогодние даты.

Встроенные WebSearch/WebFetch — запасной вариант. Если коннектор недоступен,
задачу не бросай: собери отчёт на встроенных инструментах и честно допиши в
Caveats, что часть источников проверить не удалось.

## Правила достоверности

- Даты, адреса и цены — только из проверяемых источников; у каждого события
  ставь ссылку на первоисточник (Timepad / страница организатора / канал).
- Если на какой-то день профильного события не нашлось — **так и пиши**,
  не выдумывай и не подставляй прошлогоднее. Пробел закрывается языковым
  клубом или настолками.
- Отдельно помечай события, которые уже прошли или переносятся, если они
  всплывают в выдаче как актуальные.
- Адреса языковых клубов меняются еженедельно — всегда добавляй напоминание
  сверяться с Telegram-каналом в день встречи.
- Пиши по-русски, плотно, без воды.

## Формат вывода

Только markdown-текст отчёта: без вступлений, без «вот ваш отчёт», без
markdown-ограждения ```` ``` ```` вокруг всего документа. Первая строка —
заголовок `# План на неделю в Москве (даты): куда пойти одному ради живого
общения с новыми людьми`.

## Доставка

В чат уходит **PDF-файл**, а не простыня текста:

```bash
python3 tools/send_telegram_report.py /tmp/weekly_report.md --as-pdf
```

Скрипт сам отрендерит markdown в PDF через headless Chromium, возьмёт H1 в
подпись к файлу и отправит документом. Поэтому разметка в отчёте должна быть
чистой: заголовки через `#`, подпункты дня — списком с отступом, ссылки в
формате `[текст](url)`.
